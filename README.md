# Oficina de IA Aplicada a Produto

Projeto da oficina **Além do Vibecoding**, que explora o uso de agentes de IA no desenvolvimento de software, da definição dos requisitos à entrega. O estudo de caso é um sistema de registro e acompanhamento de demandas do ensino, com escopo definido junto à plateia.

Serão utilizados **PostgreSQL** como banco de dados, **pgAdmin** para sua administração e **Docker e Docker Compose** para executar e integrar os serviços. As tecnologias do frontend e do backend ainda serão definidas.

Para subir o banco e o pgAdmin localmente, veja [infra/README.md](infra/README.md).
